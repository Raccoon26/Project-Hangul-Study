説明：動作や状態を名詞の前に置き、誰・どの物について話すかを詳しくします。動作の現在・過去・予定と、形容詞の現在の形を区別します。

結合：V語幹＋나 보다（살다→사나 보다）。A：母音/ㄹ＋ㄴ가 보다、他の子音＋은가 보다（바쁘다→바쁜가 보다）。N＋인가 보다。있다/없다＋나 보다。過去-았/었나 보다。

制約・Register：自分が確実に知る意志を、初めて推測したように機械的に言いません。요体では나 봐요/은가 봐요。形容詞にも나 보다を使う会話例はありますが、形の問題では明示した基本形に従います。
