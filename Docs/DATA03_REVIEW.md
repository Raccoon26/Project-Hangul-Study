# DATA-03 검수 기록

대상: 신규 vocabulary 250, meanings 268, examples 500, notes 48, typed vocabulary 관계 15. 기존 배포 레코드 수정 0. 실제 원본의 전체 읽기 목록은 DATA03_REVIEW_CATALOG.md이며 ID가 포함되어 있습니다.

## 검수 방식과 교정

1. DATA-02 production DB의 476개 어휘, 기존 의미·예문·note를 조회하고 후보와 비교했습니다. 아주/함께 등 이미 있는 후보를 신규 레코드로 반복 등록하지 않았습니다.
2. 한국어 기본형, 한국어 품사, 일본어 뜻과 실제 용법, 초급 level, 서술어 irregular, 의미별 예문 두 개를 작성했습니다. 이번 글은 기존 사전 예문을 복제한 것이 아닌 앱 편집 원고입니다.
3. 원본에서 추출한 250개/500문장을 두 구간으로 다시 읽고 note 48개도 별도로 검토했습니다. 예문이 단순히 표제어를 포함하는지뿐 아니라 조사·목적어·방향·뜻별 문맥을 확인했습니다.
4. 미배포 초안 교정 사례: 따라가다 예문의 방향, 개월 앞 한자어 수사(이 개월), 주일 띄어쓰기, 늘리다의 `걷는 거리를 조금씩 늘려요` 수식 관계, `남동생은 열 살이에요`와 일본어 弟의 일치, 안부 예문의 관계/경어 추정 제거. 기존 곧 예문과 같은 쌍은 `수업이 곧 시작해요`로 교체했습니다. 감다는 눈을 감는 뜻만 다루고 머리를 감는 동형어와 혼합하지 않았습니다. 들다는 들고 올리는 의미에 집중했습니다.
5. 기존 Validator, 이전 배포 검사, SQLite FK/integrity, 신규 전수 ID/의미별 예문, 검색/level/정렬/진도 교체 검사를 실행했습니다. 최종 로그와 DB의 SHA가 일치합니다.

## 다의어 및 관계

18개: 맞다, 알아보다, 빼다, 잡다, 늘다, 떨어지다, 멈추다, 고치다, 걸리다, 지나다, 움직이다, 답답하다, 복잡하다, 부드럽다, 혹시, 꿈, 힘, 뜻. 각 meaning.ordinal을 유지하며 각 의미에 예문이 연결됩니다.

관계: confusable 8 / antonym 5 / related_word 1 / synonym 1. 늘다/늘리다와 줄다/줄이다 등은 혼동 관계입니다. 가장/제일만 이번 배치에서 synonym으로 연결했습니다. 출발점 관점이 다른 따라가다/따라오다 등을 완전한 동의어로 처리하지 않았습니다.

## 중복 및 경고 판정

- 오류 0, 경고 10. `short_sentence` 5는 기존 DEV-04 한 글자 발음 예시이며 unchanged입니다.
- 중복 후보 5: 차(차량/음료), 일(일/수), 쓰다(동사/형용사), 저(대명사/관형사), 적다(형용사/동사).
- 신규 적다「書く・書き留める」는 기존 적다「少ない」와 다른 품사/의미입니다. note를 추가하고 둘 다 유지했습니다. 단순 문자열 중복 때문에 삭제하거나 하나의 ID로 합치지 않았습니다.
- 전체 문장 쌍 중복 0. 신규 각 sense 최소 한 예문, 신규 각 word 두 예문을 DB 전수 검사했습니다.
