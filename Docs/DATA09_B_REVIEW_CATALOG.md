## B01 -(으)ㄹ 때

ID `453d0f13-3727-4335-8f6a-ddff70f570ac` / plan P09

意味：〜するとき・〜のとき

説明：出来事が起きる時や、ある状態にある時を示します。-ㄹがあっても未来だけとは限りません。過去の特定の時点を振り返る-았/었을 때も一緒に学びます。

結合：V/A：母音・ㄹ語幹＋ㄹ 때（살다→살 때）、その他の子音＋을 때。N＋일 때。過去：-았/었을 때。

制約：後件の時制で全体の時を判断します。듣다→들을 때、춥다→추울 때。母音語幹に을を重ねません。尊敬は先生が오실 때のように-시-を先に付けます。

混同：가기 전에は行く前、갈 때は行く時・行く際です。어렸을 때は子どもだった頃を回想します。日本語の「時」を必ず未来として訳しません。

先行：-아요 / 어요 / 比較：-기 전에, -(으)ㄴ 후에

再読焦点：現在・過去・名詞とㄷ/ㅂ不規則。未来のㄹと誤解しない。

## B05 -다가（중단·전환）

ID `ec8a7395-00b1-494a-bada-a5f767a3e66e` / plan P46

意味：〜している途中で・〜していて

説明：進んでいた動作や状態の途中で別の動作に移ったり、別の出来事が起きたりすることを表します。この単位では動作の中断・切り替えを中心に学びます。
