## 교정한 사항

- 어떻게를 부사 기본형으로 입력했던 초안을 **어떻다 / adjective / h 불규칙**으로 수정. 어때요와 어떻게의 예를 연결했습니다.
- 쓰다의 書く/使う를 한 의미로 섞지 않고 별도 어휘 ID로 분리. 苦い라는 형용사 쓰다는 추가하지 않았고 약 예문에 그 뜻을 명시했습니다.
- 날짜의 한글 숫자·월 띄어쓰기 혼동을 줄여 3월, 4월, 5월 3일로 표기하고 읽기 설명을 부가했습니다. 2026년은 문장 예시이며 자동으로 현재 연도를 나타내는 값이 아닙니다.
- 학생 예문은 단순한 자기소개 문장으로 수정했습니다.
- 나라 예문의 어색한 자기 중심 표현을 여러 나라의 음식 예로 교체했습니다.
- 잘의 예는 합성 동사 잘하다와 혼동하지 않도록 **글씨를 잘 써요. → 字を書くのが上手です。**로 수정했습니다.
- 같은 문장 쌍 5개는 새 레코드로 반복하지 않고 여러 의미/단어에서 동일 example ID를 참조합니다. 새 447개 한국어 문장의 정확히 같은 문자열 중복은 0개입니다.
