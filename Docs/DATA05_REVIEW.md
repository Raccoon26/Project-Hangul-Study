# DATA-05 콘텐츠 검수

2026-10-03. 편집 단계의 초안 검수와 canonical source/DB 검수를 분리했다. 최종 입력은 기존 `Content/production.json` 하나이며 앱은 `Resources/content.sqlite`만 읽는다. 신규 데이터를 더 늘리지 않고 통합 검사에 시간을 배정했다.

## 확정 범위

- 初級 어휘 200개: 명사64, 동사61, 형용사32, 부사23, 표현20.
- 의미210개, 신규 문장339개, 어휘-예문 연결340개. 신규 두 항목이 동일한 문장 한 개를 공유하므로 문장을 복제하지 않았다.
- 33개 학습 note. 다의어10개는 의미2개와 각각의 예문을 분리했다: 맡기다, 맡다, 키우다, 기르다, 모으다, 쌓이다, 대충, 슬슬, 분명히, 생각이 나다.
- 일상/학교/직장 동작, 감정·성질, 회화 부사, 주거·교통·서비스, 묶음 표현을 포함한다. 새 入門/中級 단어는 없다.
- 공식 TOPIK·객관적 빈도·추측 발음은 추가하지 않았다. 우선순위400은 편집 배치 순서다.

## 별도 self-review에서 수정/제외한 사항

- 기존 시끄럽다 중복을 제거하고 색채 형용사로 교체. 부족없다·별로다처럼 이번 초급 원형 선정에 부적합하거나 품사가 불확실한 후보는 제외했다.
- 번갈아는 활용형이므로 기본형 번갈다(동사)로 등록. 차례로는 차례(명사)로 등록하고 예문에서 -로 용법을 보여준다. 밤새는 부사로 오등록하지 않고 명사로 수정했다.
- 배가 고프다/화를 내다는 기존 배고프다/화내다와의 불필요한 겹침을 줄이기 위해 목이 마르다/화를 참다로 교체했다.
- 계속해서는 기존 계속의 파생 표현을 중복 등록하지 않고 실제로로 교체했다.
- 새콤하다 예문의 일본어에서 원문에 없는 단맛을 제거. 명절을 일반적인祝日로 옮긴 문장은 주말 문맥으로 교체했다. 전기 예문은 구체적인 절전 행동으로 수정했다.
- 줍다(ㅂ), 기르다(르), 날카롭다/조심스럽다/자연스럽다/자유롭다(ㅂ), 빨갛다/파랗다/노랗다(ㅎ)를 검토. 젖다/번갈다/잠들다는 규칙 활용이다. ㅎ 현재형 직접입력은 확인된 override를 사용한다.
- predicates의 has_batchim은 기존 제작 정책대로 null. expression도 낱말 받침 metadata를 적용하지 않는다. 활용 엔진은 expression을 동사로 취급하지 않는다.
- 조사·어미·띄어쓰기·일본어 의미 보존·예문 난이도를 다시 읽어 확인했다. 희망/조건/진행/의무/허가/시도 문법을 직접 보여주는 예문11개만 기존 grammar와 연결했다. 단순 포함 여부에 의한 자동 grammar tagging은 하지 않았다.
- Validator의 기존 동형어 후보 저/차/일/쓰다/적다는 다른 품사·의미를 유지한다. 신규 표제어 후보0, 예문 한국어/일본어 쌍 중복0. 짧은 발음 예시 경고5개는 기존 발음 콘텐츠다.
