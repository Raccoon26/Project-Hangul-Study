# DEV-07 문법 자체 검수 목록

Production 원본에서 추출한 읽기용 목록입니다. 런타임 데이터 소스는 production.json→content.sqlite 하나입니다. 외부 교육 전문가 감수 완료를 뜻하지 않습니다.

검수: 기본형·결합·일본어 의미/번역·제약·문맥 정답 유일성·예문 자연스러움·기존 중복·관계를 다시 확인했습니다. 신규 원고의 중복 문장, 동생의 성별 추정, 은/는 문제의 모호한 지시문을 수정했습니다. 배포된 기존 레코드는 수정하지 않았습니다.


## -아 / 어서 — beginner

ID: 701ca81c-0e04-466d-add4-42b94643fd87

意味: 〜ので（理由）

説明: 後の内容の理由を、会話で自然に説明します。

形: 語幹の最後の母音がㅏ・ㅗ：아서／その他：어서／하다：해서

条件: 理由の用法では命令・勧誘には通常(으)니까などを使います。ここでは順序の用法は扱いません。

ポイント: 고と違い、前のことが後の理由になります。日本語の「から」と常に同じ使い方ではありません。


- 날씨가 좋아서 공원에 갔어요. / 天気がよかったので公園に行きました。


- 길이 막혀서 조금 늦었어요. / 道が混んでいたので少し遅れました。


問題: この表現の中心の意味を選んでください。 -아 / 어서

- 〜ので（理由）（正解）

- 〜してはいけない

- 〜したことがある


理由: 後の内容の理由を、会話で自然に説明します。


問題: 「忙しかったので行けませんでした」 바빠___ 못 갔어요. 

- 서（正解）

- 지만

- 고


理由: 行けなかった理由を説明する아서/어서の形です。바쁘다は바빠서になります。


## -고 싶다 — beginner

ID: 893f53f1-ebaa-48d0-82ab-aadd66e84d80

意味: 〜したい

説明: 自分がしたいことを伝えます。丁寧な会話では고 싶어요をよく使います。

形: 動詞の다を取った語幹＋고 싶다

条件: 主に動詞に付きます。他の人の希望を述べるときは、状況に応じて고 싶어 하다などを使います。

ポイント: 名詞に直接付けません。「先生になりたい」は선생님이 되고 싶어요です。


- 내년에 한국에서 일하고 싶어요. / 来年、韓国で働きたいです。


- 오늘 저녁에는 집에서 쉬고 싶어요. / 今夜は家で休みたいです。


問題: 한국에 ___ 싶어요.（行きたい） 

- 가고（正解）

- 가서

- 가면


理由: 가다の語幹가に고 싶다を付けます。


問題: この表現の中心の意味を選んでください。 -고 싶다

- 〜したい（正解）

- 〜してはいけない

- 〜したことがある


理由: 自分がしたいことを伝えます。丁寧な会話では고 싶어요をよく使います。


## -(으)니까 — beginner

ID: 919c26fd-b810-4c62-9f0c-2a25f7a30ca7

意味: 〜から（理由・判断の根拠）

説明: 話し手の判断や提案の理由を示します。命令や勧誘の前にも使えます。

形: パッチムあり：으니까／なし・ㄹ：니까（ㄹは落ちます）

条件: 不規則活用には注意します。ここでは理由の用法に絞ります。

ポイント: 아/어서も理由を表しますが、相手への提案・依頼には(으)니까が使いやすい形です。


- 밖이 추우니까 따뜻하게 입으세요. / 外は寒いので暖かい服装にしてください。


- 시간이 있으니까 천천히 이야기해요. / 時間があるのでゆっくり話しましょう。


問題: この表現の中心の意味を選んでください。 -(으)니까

- 〜から（理由・判断の根拠）（正解）

- 〜してはいけない

- 〜したことがある


理由: 話し手の判断や提案の理由を示します。命令や勧誘の前にも使えます。


問題: 寒いので窓を閉めてください。추우___ 창문을 닫아 주세요. 

- 니까（正解）

- 면

- 고


理由: 今寒いことを理由に依頼するので니까が合います。면は条件を表します。

- 〜してはいけない

- 〜したことがある

- 먹어서


理由: 語幹먹にはパッチムがあるので으면を付けます。

- 면


理由: 値段が高いことと買うことを対比するので지만です。

## -고 — beginner

ID: cc45a574-10b5-47b3-9302-bdd0468ad221

意味: 〜して、〜で（並列・順序）

説明: 二つの動作や状態をつなぎます。動作を順番に述べることもできます。

形: 動詞・形容詞の語幹＋고

条件: 理由を明確に示したいときは아/어서などを使い分けます。

ポイント: 日本語の「て」をすべて고に置き換えるのではなく、並列・順序・理由を区別します。


- 이 방은 넓고 조용해요. / この部屋は広くて静かです。


- 손을 씻고 저녁을 먹어요. / 手を洗って夕ご飯を食べます。


問題: 읽다を「読んで」とつなぐ形 

- 읽고（正解）

- 읽지만

- 읽으면


理由: 並列や順序を表す고を語幹읽に付けます。


問題: この表現の中心の意味を選んでください。 -고

- 〜して、〜で（並列・順序）（正解）

- 〜してはいけない

- 〜したことがある


理由: 二つの動作や状態をつなぎます。動作を順番に述べることもできます。

## 이 / 가 — intro

ID: 46818737-ba48-4849-8ea7-7e100908e40f

意味: 〜が（主語）

説明: 誰が・何がそうなのかを示します。質問への答えで、その人やものを示すときにも使います。

形: 名詞＋이（パッチムあり）／가（なし）

条件: 私がは제가、誰がは누가になります。

ポイント: 은/는は話題や対比、이/가は主語に注目させます。助詞だけを日本語から機械的に置き換えないようにします。


- 누가 왔어요? 친구가 왔어요. / 誰が来ましたか。友達が来ました。


- 오늘은 바람이 차가워요. / 今日は風が冷たいです。


問題: 바람 + 主語を示す助詞 

- 바람이（正解）

- 바람가

- 바람을


理由: 바람にはパッチムがあるので이です。


問題: この表現の中心の意味を選んでください。 이 / 가

- 〜が（主語）（正解）

- 〜してはいけない

- 〜したことがある


理由: 誰が・何がそうなのかを示します。質問への答えで、その人やものを示すときにも使います。

## 은 / 는 — intro

説明: 何について話すかを示します。他のものと比べるときにも使います。

形: 名詞＋은（パッチムあり）／는（なし）

問題: 対比を表す助詞を選んでください。커피는 마셔요. 하지만 우유___ 안 마셔요. 

- 는（正解）

- 은

- 를


理由: 우유はパッチムがなく、ここでは対比を表す는を使います。


問題: この表現の中心の意味を選んでください。 은 / 는

- 〜は（話題・対比）（正解）
