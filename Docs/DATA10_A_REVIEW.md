# DATA10-A 初中級 상황 듣기 Batch Self Review

이번 명시 요청은 기존 계획의 혼합 Level A를 **初中級60원문/120문제**로 조정한다. 전체 DATA10 목표150~250고유 신규 원문/300~500문제는 유지하고 이번 누적60/120, 남은 목표 범위90~190/180~380이다. 다음 Batch를 시작하지 않는다.

원문은2~3문장으로 된 짧은 연속 발화/안내다. 기존 단일 TTS 엔진이 읽으며 화자 분리/자연 대화 녹음/음성인식을 구현하거나 인증하지 않는다. 각 원문은 canonical Example1개이며 내부 문장을 따로 세지 않는다. source 재사용은 기존 Example0/신규 Example60, 신규 원문당 추가 참조1개씩60관계다. 한국어 선택지의 다른 두 후보도 이 Batch에서 실제 학습하는 원문이며 오답을 채우려고 별도 Example을 만든 것은 아니다.

엔진은 `meaning`(source 일본어와 정답 동일), `korean`(source 한국어와 정답 동일/모든 후보 실제 Example), `dictation`(source 원문 accepted), `comprehension`(내용의 정보/이유/의도/순서)을 지원한다. 새 유형·DB·채점기를 추가하지 않고 각 Listening마다 Question1개를 만든다. 이해형60개는 모두 상황 속 결정적 근거를 요구한다. 예: A11의 원래 두 시→세 시 제안, A20의 다음 주는 만나는 날이 아니라 일정을 다시 정하는 시점, A30의 미구매 이유, A55의 내일 거절/모레 대안, A59의 먼저 발표하고 싶다는 해석 부정.

각 원문의 두 문제는 새 연습103~108(화면練習104~109) 중3구간 차이로 분리했다. 원래 partial batch102/learning_order2040까지를 보존하고2060부터 추가했다. 현재 UI는 주제별 플레이리스트가 아니며 자동 SRS는 같은 source의 다른 Listening을 한 페이지에 고를 수 있다. 두 유형을 독립된 새 원문이나 원문 단위 숙달로 합산하지 않는다.

## 실제 검수

assistant가 초안 작성 후60개 한일 지문·120prompt/정답/해설·270선택지·30accepted를 별도 재독했다. 높임·행동 주체/대상·시제·否定·조건·변경 전후·정보 누락·오답의 비동치와 내부 난도를 점검했다. 初中級은 교육 편집 Level이고 공인 TOPIK/빈도 인증이 아니다. 외부 대본·음원 복사0, 독자 작성과 권한/검수 한계를 source/item_sources에 명시했다. source/provenance/difficulty/TOPIK/verified recording의 미확인 선택 필드를 추측하지 않았다.

수정은 원고20필드(9원문: A05/A08/A18/A22/A31/A35/A41/A44/A59)이며 기존 Production 교정0이다. A35의 비현실적 오답을 재방문 시점/재고 오해로 바꾸고, 문자를 메일로 한정하지 않도록 A44를 교정했다. 전체4,813기존 Example·Batch내 정규화 한국어/한일쌍/종결부호 제외 중복을 비교했으며 완전 중복0이다. A22는 승차역/목적역 해석의 혼선을 피하려고 가상의 목적역을 명시했다. 미배포 신규 엔티티의 고정 편집 timestamp도 실제 UTC 승인 시각으로 정정했으며 기존 created_at은 변경하지 않았다. 문자3-gram 근접 각3건을 재독하여 첫 문장이 기존 예문과 겹친 A08을 새 장면으로 다시 썼다. 일상 정형 표현과 주제의 일부 공유까지 의미 중복 전부가 없다는 보증은 하지 않는다. 실패 행 삭제/수량 축소0이다.

[항목별 검수/교정 원장](DATA10_A_SELF_REVIEW.json), [근접 기존 예문](DATA10_A_SIMILARITY.json), [검토할 전 원문·문제 표](DATA10_A_ITEMS.md)를 보존한다. 작성과 재독 모두 assistant이며 독립 원어민·교사 승인이 아니다.

받아쓰기 accepted는 정확한 전체 원문1개씩이다. Swift의 기존 판정이 **마지막 .!? 생략만** 허용하고 내부 문장 경계/철자·띄어쓰기는 구분한다. 동의어/의미상 맞는 자유작문·내부 부호 생략을 허용 답안에 넣지 않는다. 한국어 선택형12개는 원문 식별을 평가하고, 그 원문에도 별도 내용 이해 문제가 있어 단어 음성 재생으로 대체하지 않는다.
