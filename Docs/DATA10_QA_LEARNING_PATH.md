## 현재 가능한 순서

1. 入門·初級의 기존 짧은 의미/한국어 선택/내용이해로 소리와 뜻을 연결하고, 들은 뒤 답을 고른다. 단계 안의 모든 단문을 의무적으로 끝내고 나서 새 원문으로 넘어갈 필요는 없다. 같은 표현을 이미 이해하면 필요한 복습만 고른다.
2. 실제 기존 Grammar96개(入門22/初級20/初中級54), DATA09의 初中級3코스·18레슨/6Unit에서 해당 문형 설명을 먼저 확인한다. [180개 선택참조](DATA10_QA_PREREQUISITES.json)는 원문당1개·77고유 Grammar ID의 편집 참고다. 이는 모든 부수 문형·어휘 숙달 증명이 아니다. 미수록/변형12계열·27원문은 별도 설명/교사 확인이 필요하며 단순히 코스 배치가 있다는 이유로 해소하지 않는다.
3. A의 내용이해 batch103~105(화면練習104~106)에서 일상·약속변경·교통·구매·서비스·부탁 상황의 목적/세부를 듣는다. B batch109~111(練習110~112)에서는 감정·의견·판단·이유·결과·경험/계획·의견 차이를 듣는다. C batch115~117(練習116~118)은 안내·설명·비교·문제해결·화자 의도다. 질문은 재생 전에 볼 수 있지만 선택지/정답 문장·번역은 재생 완료 전 생성하지 않는다.
4. 결과 뒤 원문/일본어/해설을 확인하고, 어려웠던 어휘·문형을 기존 Dictionary/Grammar에서 조회한다. 기존 단문은 그 어휘나 조사의 짧은 소리·철자 연습으로 골라 쓴다. 모든 기존 단문을 맥락 이해 평가로 취급하지 않는다. 선행163후보는 기존 듣기 source와 모두 겹치며120해결/7조건부/36미해결(Level우려8포함) 그대로다. 미해결 문형이 있는 단문을 자동으로 숙달된 예문으로 추천하지 않는다.
5. 같은 원문의 두 번째 과제는 다음 짧은 학습 기회에 고른다. A batch106~108(練習107~109)은 받아쓰기30/의미18/한국어12, B112~114(練習113~115)·C118~120(練習119~121)은 받아쓰기 각60이다. 각 실제 구간은20문항 상한이며 중간 종료/기존 Resume로 나누어 쓸 수 있다. 20문항을3~10분 안에 전부 끝낸다고 보장하지 않는다.
6. SRS는 기존 Listening ID별이다. 같은 source 두 유형이 due에서 같이 나올 수 있고, 재생 횟수/받아쓰기 철자 성공을 독해·청해 전체 숙달로 해석하지 않는다. active snapshot·SRS due를 source 단위로 합치거나 초기화하지 않는다.

## 남은 교육·제품 한계

- 실제 다화자 전환, 자연 발화의 속도/억양·연결 발음 변이, 환경 소음, 화자별 음색, 진짜 안내 방송은 단일 TTS로 검증하지 못한다. 실제 청취 음원0/검청0을 바꾸지 않는다.
- 기존 단문 중심 문제는 어휘 인식/표기 연습이며 담화 추론·세부 정보 통합·화자 태도 평가가 제한적이다. 새2~3문장도 단일 발화라는 한계가 있다.
- A의 의미/한국어 선택30문항은 다른 주제의 전체 문장이 오답인 경우가 있어 청각적 미세 구별보다 큰 맥락 판별이 쉽다. 모든 오답이 똑같이 어렵거나 교수 타당도가 검증됐다는 뜻은 아니다. 새 UI gate는 보기만 읽고 답하는 재생 전 노출을 막지만 의미 선택 과제 자체의 난도를 인증하지 않는다.
- 받아쓰기 숫자는 신규150문항의 안내대로 **한글 표기**가 정답이다. `두 시`→`2시` 같은 숫자 변환·동의어는 현행 Validator/채점 계약에서 지원하지 않으므로 정답으로 약속하지 않는다. 문중 부호 입력/끝 ASCII .!? 생략/spacing warning을 구분하며 일반 입력 채점을 완화하지 않는다.
- 실제 선행 숙달에 따른 자동 필터·주제 이름 목록·원문별 SRS 중복 방지·듣기 Favorites는 구현됐다고 주장하지 않는다. 현행 Favorites는 Vocabulary/Grammar만 지원한다. 이번 사용자 데이터 검사는 그 기존 지원 범위를 보존하는 SQL 검사다.
- 문형 목록과 실제 사전 설명이 부족한12계열27원문 및 기존163후보36미해결은 다음 검토 대상으로 남는다. 이번에 Grammar 추가나 별도 Curriculum 엔진을 만들지 않는다.
