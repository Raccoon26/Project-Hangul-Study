## A01 -기 때문에 / N 때문에

ID `da6206fe-cb6b-4842-8943-da3c54c07370` / 원설계 `P35`

Meaning: 〜ので・〜のために（原因）

後の出来事が起きた原因や、判断の理由を明確に示します。動作・状態には-기 때문에、名詞には때문에を付けます。

Form: V/A語幹＋기 때문에。過去は-았/었기 때문에。N＋때문에。

Usage: 原因を述べる基本用法では、後ろに直接命令・勧誘を続ける形を避けます。依頼の理由なら-(으)니까などを検討します。丁寧さや時制は主に文末で示します。

Difference/Note: 日本語の「から」をすべて同じ形にしません。-아/어서より理由を明示する響きがありますが、常に強い非難になるわけではありません。

V/A/N 원인 결합, 과거와 명령·권유 제약. 이유와 목적을 구별했다.

- `7422d569-b6d3-4360-8601-0a6488f36183` 회의가 늦게 끝났기 때문에 점심을 늦게 먹었어요. / 会議が終わるのが遅かったので、昼食が遅くなりました。 (過去の出来事を原因として示します。)
- `0898a2dd-62d3-4bb3-a1a6-44307042f988` 이 길은 조용하기 때문에 매일 산책해요. / この道は静かなので、毎日散歩しています。 (形容詞にも기 때문에を付けられます。)
- `f278e474-9479-449b-bdfb-c5ab89033adb` 공사 때문에 버스가 다른 길로 가요. / 工事のため、バスが別の道を通ります。 (名詞공사には기を付けません。)
- `b663db5d-67b8-48bf-b513-8cc05389ad58` 설명이 자세하기 때문에 혼자서도 할 수 있어요. / 説明が詳しいので、一人でもできます。 (状態が可能性の理由になっています。)

## A02 -느라고

ID `4168b8b7-98df-431a-a90c-d83945f3df76` / 원설계 `new`

Meaning: 〜するのにかかりきりで（不都合な結果）

ある動作に時間や注意を取られ、そのために別のことができなかった場合などに使います。前の動作をした人と、後で困った人が同じ文脈を基本に学びます。

Form: 動作V語幹＋느라고。ㄹは落とします（살다→사느라고）。

Usage: 基本的に動作動詞を使い、前件に-았/었-を付けません。状態形容詞や名詞に直接付けません。通常は不利益・できなかった結果につなげます。

활동 주체·불이익 주체의 기본 동일성과 느 앞 ㄹ탈락을 확인했다.

Meaning: 〜したために（予想外の不都合）

Form: 動作V語幹＋는 바람에。ㄹ語幹はㄹを落とします。

## A04 -아/어지다（상태 변화）

ID `400d4fa2-b300-406c-9425-c7bb1a125c9d` / 원설계 `P05`

Meaning: 〜くなる・〜になる（状態の変化）

Form: Aの아/어形＋지다。춥다→추워지다、길다→길어지다、깨끗하다→깨끗해지다。

## A05 -게 되다

ID `e7ab89e5-358e-461a-893d-d87d057bc9ed` / 원설계 `P06`

Meaning: 〜するようになる・〜することになる

## A18 -(으)ㄹ 필요가 있다 / 없다

ID `f527297e-94dd-472b-928e-7bc3900b2dae` / 원설계 `P50`

Meaning: 〜する必要がある・ない

ある行動が必要かどうかを伝えます。必要がないことと、してはいけないことは異なります。

Form: V語幹＋(으)ㄹ 필요가 있다/없다。ㄹ語幹はㄹを重ねません。듣다→들을 필요가 있다。

Usage: 導入では行動の必要性を中心に扱います。名詞述語なら일 필요の形を使えますが、名詞に直接을を付けません。丁寧さ・時制は있다/없다側で示します。

Difference/Note: 필요가 없다는「不要」で、禁止の-(으)면 안 되다とは区別します。義務の-아/어야 하다や、しなくてもよい-지 않아도 되다とも比較します。

필요/불필요와 금지를 분리하고 N회원일/들을 필요의 결합을 확인했다.

- `e01fb416-fe86-47f5-912a-54cc4aba842c` 내용이 바뀌었기 때문에 다시 확인할 필요가 있어요. / 内容が変わったので、もう一度確認する必要があります。 (確認する必要があると判断しています。)
- `e7edc87f-3f6f-4400-80d8-4fe2363de93d` 이미 예약했기 때문에 줄을 설 필요가 없어요. / もう予約してあるので、列に並ぶ必要はありません。 (並ぶことを禁止しているわけではありません。)
- `60c04685-ab57-4e3b-b41f-91989f23c53d` 이 신청은 회원일 필요가 없어요. / この申し込みは、会員である必要はありません。 (名詞회원は이다を介して회원일になります。)
- `6b036676-1952-4864-8317-71dfb4b8b62e` 결정하기 전에 다른 의견도 들을 필요가 있어요. / 決める前に、別の意見も聞く必要があります。 (듣다のㄷ不規則と필요の前の分かち書きを確認します。)

問題 `7a50e7af-a597-4fcf-9e6d-fa5f53beba5e` / meaning: 「-(으)ㄹ 필요가 있다 / 없다」の基本の意味を選んでください。
내용이 바뀌었기 때문에 다시 확인할 필요가 있어요.
- a 行動することを禁止する
- b 行動が過去に起きた回数だけを示す

「行動することを禁止する」：必要性の有無と禁止は異なります。 「行動が過去に起きた回数だけを示す」：経験回数の表現ではありません。 「〜する必要がある・ない」：ある行動が必要かどうかを伝えます。必要がないことと、してはいけないことは異なります。
