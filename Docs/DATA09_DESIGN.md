# DATA-09-1 — 初中級 Grammar/Expression54개 확장 설계

**분석·설계 전용 / Production 추가0 / Content19·Schema4 유지.** P01~P54, L01~L18은 편집 키이며 runtime UUID나 배포 승인 ID가 아니다. 현재 Grammar42개는 그대로다. 장기 목표350~500개를 유지한다. 현재 기준 부족308~458개이며54개가 모두 승인되더라도 총96개, 추가254~404개가 남는다. 기존 Vocabulary expression104개를 Grammar/Expressions 목표에 중복 산입하지 않는다.

기능상 다른54개 교육 단위를 계획했다. 품사별 인용 이형태·시제, 위하다의 위해/위한, 주실래요/줄래요는 각 하나의 교육 단위 안에 묶는다. 기존 허가·금지의 단순 재기재나 기존 문법의 별명은 새 단위 수에서 제외한다. 관형·명사화는 기존 적/후에/것 같다의 특정 결합 설명을 넘는 일반 수식·내용 구성의 독립 기능으로 제안한다. P37 목적·결과 목표와 P38 지시·방침, P19 평서 인용/P20 인용 수식/P21 명령/P24 수혜자 관점의 요청 인용은 학습 기능과 오답 기준을 분리한다. 실제 제작 검수에서 중복·난도가 문제면 교체하되45~60 목표를 임의 축소하지 않는다.

## 활용 제약·일본인 설명 초안

이하 일본어는 형태·제약·혼동 포인트의 설계 초안이다. 사전·한국어/일본어 독립 검수를 통과한 Production 설명이 아니다.

### P01 관형형 -는 / -(으)ㄴ / -(으)ㄹ

V現在는/完了(으)ㄴ/予定(으)ㄹ、A現在(으)ㄴ、있다/없다は있는/없는、N인。ㄹ脱落・不規則を語ごとに確認

日本語の連体修飾と時制が一対一ではない。初回は単文修飾に限定し回想던は含めない

### P02 -기 명사화

V/A語幹+기。対象と述語の自然な組合せを限定し、기 쉽다/어렵다を補助例にする

「こと」を常に기로訳さず、-는 것との焦点差を説明

### P03 -는 것 명사화

P01の連体形+것、것이→게/것은→건/것을→걸。縮約を含むが것を消さない

動作一般の기と、具体的な出来事の것を区別。게を副詞語尾-게と混同しない

### P04 -아/어 있다

結果状態を表せる自動詞を選ぶ。앉아 있다/열려 있다。動作途中の-고 있다と区別

「〜ている」を一律に進行形にしない。着用の-고 있다は既存教材の注意も参照

### P05 -아/어지다

主にAの아/어形+지다。좋아지다。V受身などは本項の自動生成範囲外

「〜になる」の変化と、予定された行動の-게 되다を区別

### P06 -게 되다

V語幹+게 되다。本人の意志だけを強調する決定とは区別。Aへの拡張は別検討

「することになった」は決定主体より経緯に焦点。-기로 하다と同義扱いしない

### P07 -기로 하다

V語幹+기로 하다、否定は-지 않기로 하다。P02の名詞化を先行

意図-려고 하다より決定・合意が明確。이야기로/계기로は本形ではない

### P08 -게 부사형

主にA語幹+게。조용하게/편하게。形容詞の意味と後続動作の自然さを確認

P03の것이→게と区別。短い副詞との文体差も例示

### P09 -(으)ㄹ 때

V/A+(으)ㄹ 때、N일 때。過去は-았/었을 때。ㄹパッチムを重ねない

必ず未来とは限らない。前/後の時点指定との違いを説明

### P10 -고 나서

V+고 나서。同時進行や単なる羅列ではなく完了後の順序

-(으)ㄴ 후에と近いが完了の区切りを意識。-고 나니の気付きは別途保留

### P11 -는 동안 / N 동안

V現在連体形+동안、N+동안。期間の中の行動を示す

「〜までに」の期限まで含めて訳さない

### P12 -자마자

V語幹+자마자。前件語幹に過去았/었を付けず後件で時制を示す

고 나서は直後とは限らない。自動的にすべての「すぐ」を자마자にしない

### P13 -(으)ㄴ/는데（背景・対比）

V는데/ㄹ脱落、A(으)ㄴ데、N인데、있다/없다は는데。文末の柔らかい提示は補助

日本語の「が」の機械的置換を避ける。強い反論の-지만との焦点差

### P14 -(으)ㄹ까요

V+(으)ㄹ까요、ㄹは保持。自分が行う申出と一緒の提案を文脈で区別

推測の疑問まで初回で一括しない。単なる許可質問との違いを説明

### P15 -(으)ㄹ래요

意志的V+(으)ㄹ래요。主語と疑問/平叙で働きが変わる

丁寧語尾でも目上への質問は直接的になり得る。願望고 싶다と区別

### P16 -아/어 주실래요 / 줄래요

V아/어形+주실래요/줄래요。主体尊敬시は依頼先に向く。二つの丁寧度は同一教材内

日本語の「いただけますか」は場面で訳し分け。初対面/仕事では주실 수 있을까요等も補足し無制限に同義化しない

### P17 -(으)ㄹ게요

意志的V+(으)ㄹ게요。主に話し手の意志。自然現象の予測に使わない

予定-(으)ㄹ 거예요と相手への関与を比較。갈께요という綴りにしない

### P18 -아/어야겠다

V아/어+야겠다。A等は基本導入から外す。義務と겠の判断を整理

「しなければならない」と「しよう」の中間の自己判断。他者への命令にしない

### P19 간접 평서 인용 -(ㄴ/는)다고 / (이)라고 하다

V現在ㄴ/는다고、A다고、N(이)라고、있다/없다は다고。過去았/었다고/意志겠다고/未来(으)ㄹ 거라고を一教材で扱い時点を明示

日本語の「と」でも引用・条件を区別。하다以外の말하다/느끼다/판단하다への接続、主語指示の変化を説明

### P20 인용 관형형 -(ㄴ/는)다는 / (이)라는 N

P19の引用節+는、N(이)라는。過去았/었다는、意志겠다는も同一項目。명령라는との意味はP21参照

単なる連体修飾P01と「という内容」の差。-다는 이유と単なる因果の違い

### P21 명령 인용 -(으)라고 / -지 말라고 하다

意志的V+(으)라고、禁止は-지 말라고。ㄹ保持などを確認。수식 기다리라는も説明

名詞引用(이)라고と同形部分を区別。尊敬原発話세요をそのまま付けない

### P22 청유 인용 -자고 하다

意志的V語幹+자고。자다+고の자고と形態境界を区別

日本語の「しようと言った」の共同提案。寝ている자고 있다を抽出しない

### P23 의문 인용 -냐고 / -(느)냐고 하다

現在Vは냐고/느냐고、A냐고/(으)냐고、N(이)냐고。実用形と文体を辞書確認して採用

直接疑問の요をそのまま残さない。疑問詞/時制/人称を発話場面に合わせる

### P24 -아/어 달라고 / 주라고 하다

原依頼주세요の受益者が話し手なら달라고、第三者なら주라고。달라는 요구も扱う

「くれと言う」と「してあげるよう言う」の視点。単純な명령라고だけで置換しない

### P25 -(으)ㄴ/는지 알다 / 모르다

V는지/A(으)ㄴ지/N인지、過去았/었는지。意志未来はP26に分ける

疑問引用냐고と、知識の中身の未確定を区別。時間経過-(으)ㄴ 지は本項外

### P26 -(으)ㄹ지 모르다

V/A+(으)ㄹ지、N일지。疑問詞を伴う未確定判断を中心

P29の「かもしれない」は蓋然性の推測で本形とは焦点が違う

### P27 -(으)ㄴ/는/(으)ㄹ 줄 알다 / 모르다

連体形+줄 알다。時点で現在/完了/予想を区別。手順能力-(으)ㄹ 줄 알다は対比として明示

能力수 있다と混同しない。예상형と技能형を例文状況で一意にする

### P28 -나 보다 / -(으)ㄴ가 보다

V나 보다、A(으)ㄴ가 보다、N인가 보다、있다/없다나 보다。過去았/었나 보다も確認

것 같다との根拠・場面の違いを説明し絶対的交換不可ルールを捏造しない

### P29 -(으)ㄹ지도 모르다

V/A+(으)ㄹ지도 모르다、N일지도 모르다。도を省いたP26と区別

未来だけに限定せず、確言を避ける可能性として文脈を確認

### P30 -(으)ㄹ 텐데

V/A+(으)ㄹ 텐데、N일 텐데。텐데前を分かち書き。過去았/었을も別例

単なる未来予定ではない。提案の押し付けにならない場面と文末省略を説明

### P31 -아/어도（양보）

V/A아/어+도、N이어도/여도。過去았/었어도も確認。許可되다を自動補充しない

許可-아/어도 되다の教材をそのまま複製せず、反期待の後件で対比する

### P32 N(이)라도

N+(이)라도。選択の妥協/最低限と名詞条件の譲歩を場面ごとに分ける

「でも」を常に라도にしない。도の追加・さえの強調とは焦点が異なる

### P33 -기는 하지만

V/A+기는 하지만、N이기는 하지만。認める点と逆接の後件を明示

単純な-지만との差は先行内容の承認。いつでも意味が強いとはしない

### P34 -(ㄴ/는)다고 해서 … 것은 아니다

P19の引用形+해서を基本とする。해서のない-다고/라고の理由・譲歩的用法は文ごとに別途確認し、単純な省略と断定しない

報告の다고と区別。全部否定/部分否定の範囲を明確にし、봐도等への無差別置換を避ける

### P35 -기 때문에 / N 때문에

V/A+기 때문에、N+때문에、過去았/었기 때문에。一般に命令勧誘の理由としては別形を選ぶ

「から」を一律に訳さず、話し手の判断根拠(으)니까や自然な理由아/어서と比較

### P36 -는 바람에

主に動作V現在連体形+바람에、後件の過去・実際の不利益を基本とする

単なる理由すべてに使わず、予想外・不都合の文脈を明示

### P37 -도록（목적·결과 목표）

V+도록/否定지 않도록、가능수 있도록等。主節と従属節の主体は同一とは限らない

되도록という副詞は抽出除外。結果目標と意図目的기 위해の違い

### P38 -도록 하다（지시·방침）

V+도록 하다。안내/약속/조치の文脈を限定し、禁止/強制の程度は場面で説明

P37の「ように」だけと区別。主体・受け手・丁寧度を明示

### P39 -기 위해(서) / N을·를 위해(서)

意志的V+기 위해、名詞을/를 위해。名詞修飾위한も同一項目。Aの状態は普通그状態になるためのVを選ぶ

기 위한/N을 위한を別数にしない。主語が異なる結果目標には도록を比較

### P40 -(으)ㄹ까 봐

V/A+(으)ㄹ까 봐、N일까 봐。恐れや防止の主節と結ぶ

提案の(으)ㄹ까요と区別。分かち書き봐を確認

### P41 -(으)ㄹ 뻔하다

V+(으)ㄹ 뻔했다、実際は起きなかった。否定を含む場合も成立と不成立を個別確認

日本語「〜そうだった」と実現済みの結果を混同しない。하마터면は語彙として再登録しない

### P42 -더니

V/A+더니。基本は他者・外の事象の観察。時制と主語は実際の文脈を確認

P43の自分の過去行動→発見/結果と混同しない。日本語「たら」で統一しない

### P43 -았/었더니

V過去語幹+더니。基本は自分の行動→結果/発見。命令勧誘等への制約は例ごと確認

P42と時制部分だけを置換する問題を作らない。主語と結果の観察者を示す

### P44 -다 보면

動作V語幹+다 보면。反復・継続から将来の自然な結果を見込む

一度の条件(으)면、すでに気付いた-다 보니と区別

### P45 -고 나서야 / -(으)ㄴ 뒤에야

P10または完了連体形+뒤에+야。単なる後より遅れた成立を強調

P10の後関係を再登録せず「初めて」の強調が必要な文脈に限定

### P46 -다가

動作V+다가。中断/切替を中心に扱い、過去았다가の復帰は追加確認

単純順序고 나서や同時中의동안との違いを時系列で説明

### P47 -다 보니(까)

動作V+다 보니、反復・継続の後に実際の結果/発見

P44の今後の見込みと現在までの結果を対比。単発偶然だけにしない

### P48 -기만 하다

V/A+기만 하다。限定の対象と否定的評価の有無を文脈で判断

名詞만との差、いつも不満を意味するわけではないことを説明

### P49 -(으)ㄴ/는 편이다

V는 편/A(으)ㄴ 편、있다/없다는 편。相対的傾向を述べる

比較より보다や断定と区別し、平均基準を文脈に置く

### P50 -(으)ㄹ 필요가 있다 / 없다

V+(으)ㄹ 필요가 있다/없다。부정時の「不要」と「禁止」を明確にする

義務아/어야 하다、禁止면 안 되다、既存注意の지 않아도 되다を比較。不要を禁止にしない

### P51 -는 대신(에) / N 대신(에)

V는 대신/A(으)ㄴ 대신、N대신。代替と長短の補いを状況で区別

日本語の「代わりに」にある代理人と条件交換を混同しない

### P52 -는 김에

動作V現在는/完了(으)ㄴ 김에。主の行動と追加行動の機会関係を示す

単なる並列고と違い、最初の行動が機会となる。二つの意図を明示

### P53 -는 척하다

V는 척/A(으)ㄴ 척/N인 척。知覚・意図・対人registerを確認

ようだの推測ではなくふり。日本語訳で本人の本当の状態を勝手に変えない

### P54 -(으)ㄹ수록

V/A+(으)ㄹ수록。比例的傾向を扱い、必然的法則だと断定しない

日本語の「ほど」の程度比較だけではなく変化の対応。수록を分かち書きしない

## 일본인 혼동·활용 검수 설계

- 조사와 결합: 인용의 주어·발화 시점·人称, 부탁의 수혜자 달라고/주라고, 명사 인용(이)라고/명령(으)라고, 청유 자고/자다+고를 구별한다. 일본어の「と」「という」「ように」「たら」を機械的に一つの韓国語へ置き換えない。평서·의문·명령·청유와 인용 수식의 문제 지시를 명확히 한다.
- 부정 범위: 양보 아/어도와 허가 아/어도 되다, 부정 허가 지 않아도 되다, 불필요 필요가 없다, 금지 면 안 되다를 구별한다. 다고/라고가 이유·일반화 거절인 문장을 단순 발언 전달 문제로 사용하지 않는다. 것 자체의 명사화와 것은 아니다의 전체/부분 부정을 함께 확인한다.
- 결과·시간·주체: 아/어 있다와 고 있다, 게 되다와 기로 하다, 더니와 았/었더니, 다 보면과 다 보니, 나서와 나서야의 최소 문맥 쌍을 설계한다. 같은 일본어訳でも主語・観察者・時点・実現の有無を明示し、置き換え可否を断定し過ぎない。
- 불규칙 검수 행렬: 듣는다고/들어도, 묻는다고/물어도, 돕기로/도우면, 낫다(병이 낫다/V)의 낫는다고/나으면과 낫다(더 좋다/A)의 낫다고, 살다의 산다고/살 거라고, 그렇다고/그러면, 지내다 보면을 서로 다른 결합 조건으로 확인한다. ㄷ/ㅂ/ㅅ/ㅎ/르/으/ㄹ·하다와 규칙 동형어를 분리하고 뜻에 따라 사전 예외를 검토한다. 예시형은 검수 기준 초안이며 이번 Swift 생성 실행 결과가 아니다.
- 일본어: 事実/推測、過去/意志、依頼の相手と受益者、丁寧さ、否定の範囲を独立再読する。直訳による主語や確実性の追加を避ける。日本語設計文は独立原語話者・教師の承認を得ていない。後続制作で辞書/出典・権利/実際の確認方法を記録し公式等級や監修済みを捏造しない。
