# DATA-04 자체 검수 기록

## 범위와 결과

원본 source 작성 후 별도 pass로 30개 문법의 핵심 뜻·상세 일본어·형태·조건·note, 60개 연결 예문 쌍, 60개 문법 문제의 지시문·선택지·정답 이유를 다시 검토했습니다. 듣기 3개는 기존/신규 canonical example을 참조하며 별도 transcript를 만들지 않았습니다. 53개 예문은 신규, 7개는 기존 ID를 재사용합니다.

- ㄹ 처리: 살려고(유지), 삽니다/여세요(탈락), 산 적/만든 후(탈락 후 ㄴ), 살 거/살 수(기존 ㄹ), 지하철로를 구분했습니다.
- 語幹 설명을 입문 현재형에 추가하고 받침 용어는 일본어 パッチム으로 통일했습니다.
- 존재와 명사 부정, 안과 못, 허가와 가능, 희망과 의도, 현재 진행과 결과 상태의 차이를 제한 범위와 함께 설명했습니다.
- 과거/미래/현재 추측을 한 항목에 과도하게 합치지 않았습니다. -고 있다는 동작 진행, (으)로는 수단, -(으)세요는 요청, 것 같다는 현재 추측을 우선합니다.
- 정답이 동의어·다른 register로도 성립할 수 있는 요청형 문제는 요구하는 -(으)세요를 지시문에 명시했습니다.
- -기 전에 문제는 불완전한 자모 조각 선택지를 없애고 나가기 전에/나간 후에/나가고 나서로 수정했습니다.
- 질문의 오답도 대체로 실재하는 다른 시제·태도·관계 표현입니다. 지시문의 번역/시제/순서 조건에 따라 정답이 하나가 되도록 검토했습니다.
- `여기에 앉으세요.`의 기존 번역 `ここに座ってください。`와 신규 번역 후보 `こちらに座ってください。`는 의미상 중복으로 판단하여 기존 ID를 사용했습니다. 문자열 일치만으로 무조건 삭제하지 않았습니다.
- 신규 grammar의 정규화 표현 중복은 없습니다. 기존 v10 grammar 12개와 개념 범위를 비교했습니다.
- 기존 -고 싶다의 note만 확장했습니다. 다른 기존 grammar 설명이나 사용자 ID는 변경하지 않았습니다.

## 확인 자료

설명과 예문은 자체 작성했습니다. 사전의 긴 정의나 예문을 복사한 데이터셋이 아닙니다.

- 국립국어원 온라인가나다, 「ㄹ탈락」, 2026-04-23 답변: https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=330045
  - 살다/놀다와 -려고 결합에서 ㄹ을 유지하는 것을 본문으로 확인했습니다.
- 한국어기초사전 `-ㄴ 적이 있다` 검색 결과: https://krdict.korean.go.kr/jpn/dicSearch/SearchView?ParaWordNo=73971
  - 검색 결과의 용법 정보를 참고했습니다. 상세 페이지 접근은 실패했으므로 상세 본문을 모두 검토했다고 주장하지 않습니다.
- 국립국어원 어문 규범: https://korean.go.kr/kornorms/m/m_regltn.do
  - 검색 결과에서 의존 명사 띄어쓰기·축약 정보를 참고했습니다. 해당 실행의 직접 페이지 요청은 403이어서 전체 규정 검토로 간주하지 않습니다.

자동 Validator는 언어적 사실성이나 음성을 인증하지 않습니다. 이 기록은 자체 검수이며 외부 한국어 교육 전문가·일본어 편집자 감수 및 기기 TTS 청취는 남아 있습니다.
